# Security Policy

## Supported Versions

We provide security updates for the current major version of the skill documentation.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities by emailing security@example.com.

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix

We aim to respond within 5 business days and will coordinate disclosure responsibly.

Do not open public issues for security vulnerabilities.
